# Knowledge base

Obsidian vault for the thesis. Open **this folder** (`kb/`) as the vault, not the repository root.

## Folders
| Folder | Contents | Note name |
|---|---|---|
| `chapters/` | One hub note per chapter: the argument in order, linking to its claims | `03-valdx` |
| `claims/` | One claim per note | The claim as a full sentence |
| `concepts/` | Definitions and background ideas | Concept name |
| `methods/` | Mathematical and experimental methods | Method name; project (methods may differ between projects) |
| `papers/` | Literature notes | `@<citekey>` (matches `thesis/references.bib`) |
| `decisions/` | Why a method, parameter or dataset was chosen | `YYYY-MM-DD <decision>` |
| `inbox/` | Unsorted notes; triage weekly | anything |
| `voice/` | How to write in my voice: `style`, `spag` (spelling, punctuation, grammar), `examples`. Guides drafting; never evidence | fixed |
| `ref-theses/` | Notes generated from the example theses: hubs, rhetorical moves, concept candidates. Never evidence | `<author>/<note>` |
| `_pdf/` | Local PDFs for paper notes (gitignored) | `@<citekey>.pdf` |
| `_templates/` | Note templates (set as the Templates folder in Obsidian) | — |

`review-queue.md` is generated by `tools/kb-lint/lint.py --write`: every note with `needs_review: true`, grouped by reason, plus quotes not found in their PDF. Do not edit it by hand.

`notation.md` is generated the same way: every symbol in a concept's `notation:` field. One symbol has one meaning across the vault (lint check 10); the canonical choices are recorded in `decisions/`. Do not edit it by hand.

Sources write their own notation. A paper note records it once, in a `## Notation` table: `| Source | Meaning in this source | Canonical | Note |`, where Canonical is one `$symbol$` declared by a concept, or `—` with the Note saying how the thesis writes it. Concepts always write canonical notation and point at the map from their `Source:` line, e.g. `(notation: [[@bmsb2012ch12#Notation]])`. Write `\mid` and `\Vert`, not a bare `|`, inside table cells.

[tools/kb-seed](../tools/kb-seed/README.md) seeds paper notes and PDFs from Zotero, finds quotes in PDFs, checks that every citation in a `.tex` file is accounted for, and promotes verified claims.

## Rules
- One idea per note.
- Put links inside the body text where they are used, not in "related" lists.
- A claim leaves `draft` only with evidence: a figure ID in `figures`, or a block link such as `"[[@smith2020#^c1]]"` in `cites` whose quote the lint has found in the PDF (`quote_check: pass`).
- Quote wikilinks in frontmatter: `- "[[@smith2020#^c1]]"`.
- `quote_check` is written only by the lint; `reviewed` only by me.
- Example-thesis notes (`ref-theses/`) are never cited as evidence; cite the primary paper.
- Concept and method notes back definitions, equations and derivations with `sources:` block links (`- "[[@key#^c1]]"`), checked like claim `cites`. For an equation, quote the sentence that introduces it and give the equation number and page in the body; quotes cannot capture the maths itself.
- Equations go in a concept's `## Equations` section as a `$$ … $$` block followed by a block ID line (`^eq-<name>`), a `Source:` line (block link, equation number, page) and, when a manuscript already writes it, a `Manuscript form:` line (`path#L<n>`, never evidence). Derivations go in `## Derivation`, one numbered step per line, each citing a source equation or marked "(step ours)". Declare every symbol in `notation:`.
- Project-specific formulations (losses, Work Done) are method notes, not concepts; they link the concepts whose symbols they use.
- Method notes link to code as `<submodule>@<sha>:<file>#L<start>-<end>`.
- Run `python3 tools/kb-lint/lint.py` (from the repository root) before relying on a claim; see [tools/kb-lint](../tools/kb-lint/README.md).
- Chapter hub notes list claims in argument order, so each hub reads straight through as an outline of the chapter.
- Source trust order, hub upkeep and what belongs in a hub's Gaps section are set in `AGENTS.md` ("Sources and hub upkeep"). In short: my manuscripts are checked sources, hub lines are never cut for weak citations, and Gaps list only what blocks writing.
- Figures are referred to by their ID (the folder name under `figures/`) everywhere: KB, `.tex` and analyses.
