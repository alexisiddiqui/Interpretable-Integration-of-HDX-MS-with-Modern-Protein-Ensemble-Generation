# Inferential Structure Determination from NMR Data

Chapter 12 of Hamelryck, Mardia and Ferkinghoff-Borg (eds), *Bayesian Methods in Structural Bioinformatics*, Springer 2012 (DOI 10.1007/978-3-642-27225-7). Author(s): Habeck, Michael. Printed pages 287–312.

PDF note: the PDF holds this chapter only, so PDF page = printed page − 286. The book prints one shared reference list at the end, which is not in this PDF. Use this chapter for mathematical definitions and derivations; quote the sentence that introduces an equation and give the equation number in the citing note's body.


## Main point

Inferential structure determination treats structure calculation as Bayesian inference: a forward model and an error model give the likelihood, the force field gives the prior, and nuisance parameters such as the error scale are inferred with the structure. The resulting ensemble describes uncertainty, not dynamics.
