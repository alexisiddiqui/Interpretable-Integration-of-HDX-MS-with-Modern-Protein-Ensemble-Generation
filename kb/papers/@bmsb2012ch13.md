# Bayesian Methods in SAXS and SANS Structure Determination

Chapter 13 of Hamelryck, Mardia and Ferkinghoff-Borg (eds), *Bayesian Methods in Structural Bioinformatics*, Springer 2012 (DOI 10.1007/978-3-642-27225-7). Author(s): Hansen, Steen. Printed pages 313–342.

PDF note: the PDF holds this chapter only, so PDF page = printed page − 312. The book prints one shared reference list at the end, which is not in this PDF. Use this chapter for mathematical definitions and derivations; quote the sentence that introduces an equation and give the equation number in the citing note's body.


## Main point

Small-angle scattering gives low-information, ensemble-averaged data, so structure determination needs regularisation. Bayesian methods set the regularisation weight and the noise level from the data, give error estimates and compare models by their evidence.
