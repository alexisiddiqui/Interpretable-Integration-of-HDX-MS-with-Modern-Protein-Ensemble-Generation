# pK Values of the Ionizable Groups of Proteins (2006)

## Main point

Potentiometric titration of ionizable groups placed in blocked alanine pentapeptides gives reference pK values for groups free of charge–charge interactions and burial. Several values differ from the Nozaki–Tanford set that the literature had been using.

## Claims

- Model pK values were measured in alanine pentapeptides with the residue of interest in the middle and both termini blocked, so the group sees a local environment like that of an unfolded, uncharged protein, without charge–charge interactions and largely without burial. ^c1

## What I use from it

The reference (model) pKa values for Asp, Glu and His that the `pKa` concept quotes, and Eq. 1 as a source for the Henderson–Hasselbalch protonated fraction. The Asp value was later revised to 3.94 ([[@grimsleySummaryMeasuredPK2009]] ^c6).

## Disagreements / limitations

The abstract gives 0.1 M KCl; the Table 2 footnote says 0.1 M NaCl.
