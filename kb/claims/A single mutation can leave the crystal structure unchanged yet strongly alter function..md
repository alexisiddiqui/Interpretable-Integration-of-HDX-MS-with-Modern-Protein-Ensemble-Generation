## Argument

In PKA, a single Tyr mutation has minimal effect on NMR chemical shifts, the crystal structure and nucleotide binding, but strongly reduces substrate affinity ([[@lisiAllosteryEnzymeCatalysis2017#^c6]]). A structure-level comparison would call the mutant unchanged. This replaces the unsupported p53 example as the case where structure and function come apart ([[population shift]]).

## Caveats

PKA is not a disease example. If a disease case is wanted, p53 needs a primary source showing near-identical mutant crystal structures; none is in the KB.
