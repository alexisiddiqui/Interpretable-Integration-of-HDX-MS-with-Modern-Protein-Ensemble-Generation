\section{Dataset Processing}
\label{app:valdx-hdx-data}

We applied filtering criteria so that the data used for ensemble optimisation were informative and compatible with the Best--Vendruscolo (BV) model.\supercite{bestStructuralInterpretationHydrogen2006} We performed all fractional uptake calculations and normalisations before any filtering.

As detailed in \cref{tab:valdx-data}, BRD4, HOIP, and LXR$\alpha$ uptake values were normalised using peptide-level fully deuterated controls and were therefore corrected for back-exchange. BPTI instead comprises NMR-derived residue-level protection factors, for which a FullD control is not applicable. The MBP data did not include a FullD control and were scaled to the maximum measured time point. This scaling does not correct back-exchange. Consequently, the absolute MBP uptake values may be systematically underestimated, with peptide-specific deuterium loss potentially distorting relative uptake as well as its overall scale. We retained MBP as a publicly available benchmark spanning a distinct protein system, but used it only during protocol development and do not report its results in \cref{ch:valdx}. Although $\text{Work}_\text{scale}$ (\cref{sec:valdx-work}) reports a global shift in predicted protection, it cannot correct peptide-specific back-exchange; uncorrected MBP results must therefore be interpreted with this limitation.

\begin{itemize}
    \item \textbf{Time point filtering.} We removed time points where the replicate precision (relative standard deviation, RSD) exceeded 5\%. This threshold typically corresponds to very short or very long deuteration times. Excluding poorly informative time points removes data that the single-exponential BV model describes poorly. This threshold aligns with high-precision HDX-MS estimates.\supercite{hudgensInterlaboratoryComparisonHydrogenDeuterium2019}
    \item \textbf{Peptide filtering.} We removed peptides that were short ($<5$ residues) or had low information content (saturation difference $<0.05$).
\end{itemize}

All filtering was performed before any splitting or optimisation.

\section{Ensemble Generation}
\label{app:valdx-ensemble-generation}

\subsection{AlphaFold Generation and Geometric Filtering}
\label{app:valdx-af2}

\paragraph{Featurisation of ensembles.}
Since AF2 structures natively do not contain hydrogens, these must be added post hoc, because the BV model of \cref{eq:bg-bv-feature} counts contacts to the amide hydrogen. Backbone amide H atoms were added using standard peptide geometry (N--H bond length $1.02\,\text{\AA}$).\supercite{yaoNMRDeterminationAmide2008} Backbone amide proton coordinates were computed using barycentric coordinates of the peptide plane.

\paragraph{AlphaFold MSA subsampling.}
ColabFold was used to generate the AlphaFold2 (AF2) ensembles.\supercite{mirditaColabFoldMakingProtein2022} MSA subsampling\supercite{monteirodasilvaHighthroughputPredictionProtein2024} was performed over a range of 1--127 Max Sequences with Max Extra Sequences set to twice the Max Seq value. Each parameter set was used to generate 100 structures (20 seeds). For each protein, a single recycling step was used with no minimisation, generating 12,700 structures in total.

\paragraph{AlphaFold ensemble cleaning.}
Since AF2 generates structures according to a statistical potential, this leads to the inclusion of unnatural or implausible structures in the ensemble. This is more prevalent at lower recycle counts. To quantify structure confidence, predicted Local Distance Difference Test (pLDDT) from AF2 is used in addition to predicted Template Modelling (pTM). While high structure quality (pLDDT and pTM) correlates well with crystal structures, the design of AF2 means that the generated ensemble is biased towards structures that exist within the training data. For large, flexible or disordered proteins this represents a problem as pLDDT no longer is able to provide a reliable estimate of structure quality. As a result, fixed confidence-score cut-offs using AF2 predicted structure quality measures are not sufficient to clean ensembles \textit{a priori}. Other works in the literature use system-specific collective variables to identify relevant conformations; however, this requires prior knowledge of the protein system, which may be unavailable, and may introduce bias about what its structures should look like.

No widely adopted system-agnostic protocol is standard; we therefore developed an approach to filter ensembles using knowledge that exists for almost any protein. These filters are designed to handle some consistent AF2 failure modes, which include over-folding, mis-folding and under-folding. We hypothesise that the prevalence of implausible structures is linked to the size, flexibility and availability of crystal structures. Our strategy involves the use of multiple, broad measures of protein structure to successively filter structures based on percentiles chosen based on rules defined by broad characteristics of the protein (\cref{tab:valdx-af2-filter-thresholds}).

Structures were first filtered using protein-specific percentile thresholds for pLDDT and pTM (\cref{fig:valdx-af2-confidence}). Further structural screening used contact order, reference-based structural local-distance correlation, mean inter-residue distance, and clash criteria (\cref{fig:valdx-af2-contact-order}). The structural local-distance correlation measures the Pearson correlation between corresponding local C$\alpha$--C$\alpha$ distances in each candidate structure and a fixed reference structure. Reference selection and filtering thresholds are described below and in \cref{tab:valdx-af2-filter-thresholds}.

After filtering, we cluster retained structures in the first five principal components of their all-pair C$\alpha$ distance representation and select the structure nearest each of 20 K-means centroids. We calculate the mean pairwise structural local-distance correlation among these centroid-representative structures to assess local structural coherence (\cref{eq:valdx-structural-ldc}). This assessment concerns similarity of local distance patterns and does not establish experimental accuracy.

\paragraph{Structural local-distance correlation.}
We compared local geometry between structures using Pearson correlation of corresponding C$\alpha$--C$\alpha$ distance vectors. For structures $a$ and $b$, the comparison includes the same residue-pair indices in both vectors, restricted to pairs whose distances are at most $8\,\text{\AA}$ in both structures:
\begin{equation}
\begin{aligned}
d_{mn}^{(a)} &= \lVert\mathbf r_m^{(a)}-\mathbf r_n^{(a)}\rVert_2,\\
\mathcal N_{ab} &= \{(m,n):m<n,\ d_{mn}^{(a)}\leq8\,\text{\AA},\
d_{mn}^{(b)}\leq8\,\text{\AA}\}.
\end{aligned}
\label{eq:valdx-structural-ldc-pairs}
\end{equation}
\begin{equation}
L_{ab}=\operatorname{corr}_{\mathrm P}
\left([d_{mn}^{(a)}]_{(m,n)\in\mathcal N_{ab}},
[d_{mn}^{(b)}]_{(m,n)\in\mathcal N_{ab}}\right).
\label{eq:valdx-structural-ldc}
\end{equation}
Here, $\operatorname{corr}_{\mathrm P}$ denotes Pearson correlation, with corresponding residue pairs ordered identically in both vectors. The coefficient lies between $-1$ and $1$ when defined. It measures agreement between local distance patterns rather than correlated motion over frames.

For post-filter assessment, we calculate correlations between distinct structures selected nearest to the 20 K-means centroids in the first five principal components of the all-pair C$\alpha$ distance representation. The summary is the mean of the valid off-diagonal comparisons; self-comparisons are excluded. Representative selection requires mapping indices within the retained-frame array back to the original trajectory indices.

During filtering, each candidate structure is scored against a fixed reference using Pearson correlation of corresponding local C$\alpha$ distances. The cleaning figures identify this reference as the highest-pLDDT structure (Max-pLDDT); protein-specific correlation percentiles are listed in \cref{tab:valdx-af2-filter-thresholds}.

\subsection{Single-Start, Multiple-Start and T-FES Protocols}
\label{app:valdx-md-protocols}

\paragraph{MD-1Start.}
We selected the single highest confidence AF2 structure and performed 5 replicates of 20 ns of production MD. This represents the standard approach of initiating simulation from a single, high-quality structure to test if conventional MD suffices to sample relevant states. To ensure the stability of the structures, 10 ns of unrestrained MD was additionally performed before the start of the production step.

\paragraph{MD-10Start.}
To represent a more diverse approach to generating ensembles with respect to HDX-MS data, the filtered AF2 (AF2-Filtered) ensemble was clustered by k-means ($k=10$), and the ten representative structures were used as diverse starting structures, which were then equilibrated using the same protocol as MD-1Start. To maintain a comparable computational budget to MD-1Start, each starting structure was run with a single replicate of 5 ns and 10 ns for relaxation and production simulations, respectively.

\paragraph{T-FES.}
To represent the most diverse range of fully plausible structures possible within a reasonable compute budget we modified an equilibrium-MD sampling approach, Frontier Expansion Sampling (FES).\supercite{zhangFrontierExpansionSampling2020} We adjusted the algorithm to concurrently sample across diverse starting structures with different topologies, producing multi-Topology Frontier Expansion Sampling (T-FES). To seed the initial conformations we combine both MD ensembles generated previously (MD-1Start and MD-10Start). We perform 20 cycles, capped at 200 short (0.1 ns) simulations per cycle which generates a maximum of 400 ns of short equilibrium-MD simulations. To maintain compatibility with the previous simulations the relevant GROMACS simulation files were converted into AMBER file formats compatible with OpenMM using ParmEd.\supercite{shirtsLessonsLearnedComparing2017} We retained OpenMM's default Langevin integrator, but added a Monte Carlo Barostat to match the Parrinello-Rahman barostat used in the GROMACS simulations. Each short simulation is preceded by an ultra-short equilibration (2000 steps, 1 fs time-step) to facilitate particle-velocity re-initialisation. The reported MD-TFES ensembles therefore use the modified multi-topology T-FES implementation with Monte Carlo barostat pressure coupling, distinct from the original Frontier-Expansion-Sampling codebase.

\section{Synthetic Data Generation and Simulator Validation}
\label{app:valdx-synthetic}

\subsection{TeaA State Assignment}
\label{app:valdx-teaa-states}

We repeated the trajectory clustering on a sliced (1:50) subset of the original trajectory. Trajectory clustering was performed by aligning all frames to each reference (Open and Closed) and computing the RMSD. Frames were sorted into Open and Closed clusters if structures were less than 1.0~\AA\ from one of the reference structures.

\subsection{Kinetic Uptake Simulator}
\label{app:valdx-kinetic-simulator}

Writing the per-residue state probabilities as $\mathbf{p}_i(t)=(C_i,O_i,D_i)^\top$, the system obeys $d\mathbf{p}_i/dt=\mathbf{K}_i\mathbf{p}_i(t)$ with generator matrix
\begin{equation}
    \mathbf{K}_i=
    \begin{pmatrix}
    -k_{\text{op},i} & k_{\text{cl},i} & 0 \\
    k_{\text{op},i} & -(k_{\text{cl},i}+k_{\text{int},i}) & 0 \\
    0 & k_{\text{int},i} & 0
    \end{pmatrix},
    \label{eq:valdx-kinetic-generator}
\end{equation}
solved as $\mathbf{p}_i(t)=\exp(\mathbf{K}_i t)\,\mathbf{p}_i(0)$ from the equilibrium initial condition $O_i(0)=1/P_{f,i}$, $C_i(0)=1-1/P_{f,i}$, $D_i(0)=0$; fractional uptake is read from $D_i(t)$. The rates are those of \cref{eq:valdx-kinetic-rates}. Before generating the calibration datasets used in \cref{ch:valdx}, we ran three independent checks against this implementation.

First, the numerical matrix exponential (\texttt{scipy.linalg.expm}) was compared against an analytic eigenvalue-decomposition solution of the same rate matrix. The maximum absolute error across all tested residues and time points was $4.80\times10^{-7}$, consistent with floating-point precision rather than a modelling error.

Second, we confirmed that the three-state model reduces to the standard EX2 approximation as $\rho$ grows large. At the reference condition $\rho=1000$, exact kinetic uptake matched the closed-form EX2 prediction to a maximum absolute error of $3.68\times10^{-4}$ in fractional uptake, equivalent to 0.0368 percentage points.

Third, probability was conserved exactly, with $C_i(t)+O_i(t)+D_i(t)=1$ at every tested time point, confirming that the generator matrix was constructed correctly.

These three checks were run across 294 TeaA residues, 106 time points, six validation values of $\rho$ ($1000$, $100$, $10$, $1$, $0.1$ and $0.01$), and four additional pathological parameter regimes chosen to stress-test \cref{eq:valdx-kinetic-rates}. The kinetic misspecification experiments reported in \cref{ch:valdx} used three conditions, $\rho \in \{1000,1,0.01\}$. All checks passed. The validation assertions and the accompanying gate report are provided with the deposited code (\texttt{02\_validate\_simulator.py}; \texttt{simulator\_gates.json}).

\subsection{Peptide Map and Measurement Noise}
\label{app:valdx-peptide-noise}

Fractional peptide uptake was calculated by averaging over eligible residues, excluding the peptide N-terminal amide and residues absent from the exchangeable-residue feature set. Uptake was evaluated at 0.167, 1, 10, 60 and 120 min, with no additional D$_2$O fraction scaling.

Peptide fragments for the kinetic misspecification experiments (\cref{sec:valdx-synthetic}) were generated from the TeaA sequence using a stochastic, sequence-dependent cleavage model rather than a fitted pepsin-specificity predictor. For every peptide bond between residues $i$ and $i+1$, an unnormalised cleavage weight was calculated as
\begin{equation}
    W_i = W_{P_1}(a_i)\,W_{P_1'}(a_{i+1})\,M_i,
    \label{eq:valdx-pepsin-weight}
\end{equation}
where $a_i$ and $a_{i+1}$ are the residues immediately before and after the bond. Cleavage was prohibited outright when either residue was proline. A proline at the $P_2$ or $P_2'$ position multiplied the weight by 0.15 for each occurrence, giving $M_i$. The cleavage probability was
\begin{equation}
    p_i = \mathrm{clip}(sW_i,\,0,\,1),
    \label{eq:valdx-pepsin-probability}
\end{equation}
with scale factor $s=0.9632476$, calibrated to give an expected inter-cleavage spacing of 10 residues.

Relative $P_1$ propensities were F/L 1.00, W 0.90, Y 0.80, M 0.60, A 0.40, V/I 0.35, E 0.30, Q 0.25, C 0.20, S/N/H 0.12, T 0.15, G 0.10, D 0.08, K 0.06, R 0.05, and P 0. Relative $P_1'$ propensities were F/L 0.90, W 0.80, Y 0.70, M 0.50, A 0.40, V/I 0.35, E 0.30, Q 0.25, C 0.20, T 0.18, S/N/G/H 0.15, D 0.10, K/R 0.08, and P 0.

Each simulated digest sampled every bond independently as a Bernoulli trial using these probabilities. Fragments of 5 to 15 residues were retained, duplicate fragments were removed, and independent digests were pooled until the target mean residue coverage of 2.5 was reached. Ten pooled digests, generated with seed 20260813, produced 94 peptides with mean residue coverage 2.68.

Because the peptide map was generated once from sequence alone, it does not depend on structure, solvent accessibility, charge state, or predicted MS detectability, and it is identical across kinetic regimes and fitting arms. This is a simplified propensity model rather than a validated pepsin-specificity predictor and should be interpreted accordingly.

Measurement noise (Gaussian, $\sigma=0.02$ in fractional uptake) was drawn from a single matched noise realisation shared across kinetic conditions, recorded in the per-condition sidecar files (\texttt{noise\_rho<$\rho$>\_n0.json}). The three peptide-split replicates used seeds 240513, 240514 and 240515; the overall study seed (240513) is additionally recorded in each sweep's invocation record. Simulator, digestion-model and fitting code are deposited alongside the repositories listed in \cref{app:valdx-implementation}.

\section{Clustering and Structural Perturbation Algorithms}
\label{app:valdx-perturbations}

\subsection{Poisoning Algorithms}
\label{app:valdx-poison-algorithms}

\Cref{alg:valdx-gaussian-noise,alg:valdx-coordinate-mixing,alg:valdx-proton-shuffling} give the three operations described in \cref{sec:valdx-decoys}. Each acts on every frame of the parent ensemble.

\begin{algorithm}[htbp]
\caption{Gaussian noise structure poisoning}
\label{alg:valdx-gaussian-noise}
\footnotesize
\begin{algorithmic}[1]
\Require Ensemble $X = \{x_1, x_2, \ldots, x_n\}$
\Require Output path for poisoned structures
\Ensure Poisoned ensemble with residue-specific Gaussian noise
\State Initialize $\sigma_{\text{residue}} \leftarrow \{\}$ \Comment{Residue variance dictionary}
\For{each structure $x \in X$}
    \For{each residue $r$ in $x$}
        \State Store coordinates: $\sigma_{\text{residue}}[r.\text{id}].append(r.\text{positions})$
    \EndFor
\EndFor
\For{each residue ID $r_{\text{id}}$ in $\sigma_{\text{residue}}$}
    \State $\text{positions} \leftarrow \text{array}(\sigma_{\text{residue}}[r_{\text{id}}])$
    \State $\sigma_{\text{residue}}[r_{\text{id}}] \leftarrow \text{var}(\text{positions}, \text{axis}=0)$
\EndFor
\For{each structure $x \in X$}
    \For{each residue $r$ in $x$}
        \State $\text{noise} \leftarrow \mathcal{N}(0, \sqrt{\sigma_{\text{residue}}[r.\text{id}]})$
        \State $r.\text{positions} \leftarrow r.\text{positions} + \text{noise}$
    \EndFor
    \State Write poisoned structure to output
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[htbp]
\caption{Coordinate mixing structure poisoning}
\label{alg:valdx-coordinate-mixing}
\footnotesize
\begin{algorithmic}[1]
\Require Ensemble $X = \{x_1, x_2, \ldots, x_n\}$
\Require Output path for poisoned structures
\Ensure Poisoned ensemble with randomly permuted coordinates
\For{each structure $x \in X$}
    \State $\text{coordinates} \leftarrow x.\text{atoms.positions}$ \Comment{Extract all atomic coordinates}
    \State $\text{shuffled\_coords} \leftarrow \text{random\_permutation}(\text{coordinates})$
    \State $x.\text{atoms.positions} \leftarrow \text{shuffled\_coords}$
    \State Write poisoned structure to output
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[htbp]
\caption{Backbone proton shuffling structure poisoning}
\label{alg:valdx-proton-shuffling}
\footnotesize
\begin{algorithmic}[1]
\Require Ensemble $X = \{x_1, x_2, \ldots, x_n\}$
\Require Output path for poisoned structures
\Ensure Poisoned ensemble with shuffled backbone proton positions
\For{each structure $x \in X$}
    \State $\text{backbone\_H} \leftarrow \text{select\_atoms}(\text{``backbone and name H''})$
    \State $\text{original\_coords} \leftarrow \text{backbone\_H.positions.copy}()$
    \State $\text{shuffled\_coords} \leftarrow \text{random\_shuffle}(\text{original\_coords})$
    \State $\text{backbone\_H.positions} \leftarrow \text{shuffled\_coords}$
    \State Write poisoned structure to output
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Poisoned Ensemble Construction}
\label{app:valdx-poison-construction}

The unmodified and poisoned parent ensembles were each reduced to representative structures by the same procedure. All atomic Cartesian coordinates of every frame were projected onto their first 50 principal components, and k-means clustering ($k=1000$, fixed random seed) was applied in that projection. The first frame of each cluster, in trajectory order, was taken as its representative. The 1000 representatives of the unmodified ensemble formed the base ensemble. Poisoned representatives were ordered by squared Euclidean distance. Each distance compared a representative in the poisoned Cartesian-coordinate projection with the mean projection of the unmodified parent ensemble in a separate 50-component PCA of coverage-filtered C$\alpha$ pair distances. The poisoned ensemble at dose $n$ comprised the base ensemble followed by the first $n$ ordered poisoned representatives, with $n=1$, 10, 100 and 500 for 0.1, 1, 10 and 50\%. The two projections were fitted separately, so this ordering is fixed and reproducible but is not a distance from the unmodified ensemble average in a shared space.

\subsection{Curve-of-the-Knee Algorithm}
\label{app:valdx-knee}

\begin{algorithm}[htbp]
\caption{Curve-of-the-knee $\gamma_\text{HDXer}$ optimisation}
\label{alg:valdx-knee}
\footnotesize
\begin{algorithmic}[1]
\Require Set of candidate values $\gamma_\text{HDXer}= \{\gamma_1, \gamma_2, \ldots, \gamma_n\}$
\Require Corresponding error values $E = \{e_1, e_2, \ldots, e_n\}$
\Require Apparent work values $W = \{w_1, w_2, \ldots, w_n\}$
\Ensure Optimal $\gamma^*$
\State Initialize $x \leftarrow W$, $y \leftarrow E$
\State Sort data points by $x$ values
\If{$|x| = 1$}
    \State \Return $\gamma_1$
\ElsIf{$|x| = 0$}
    \State \textbf{raise} ValueError(``No valid gamma values found'')
\EndIf
\State $\gamma^* \leftarrow \text{null}$
\State \textit{// Method 1: Angle-based selection}
\State $\theta \leftarrow []$
\For{$i = 1$ to $|x|-1$}
    \State $\theta_i \leftarrow \arctan\left(\frac{y_{i+1} - y_i}{x_{i+1} - x_i}\right)$
    \State Append $\theta_i$ to $\theta$
\EndFor
\If{$\theta \neq []$}
    \State $\theta^* \leftarrow \arg\min_{\theta_i} |\theta_i + \pi/4|$
    \State $\gamma^* \leftarrow \gamma_{\text{index}(\theta^*)}$
\EndIf
\If{$\gamma^* = \text{null}$}
    \State \textit{// Method 2: Maximum distance from regression line}
    \State Fit linear regression: $\hat{y} = mx + b$ where $(m, b) = \text{polyfit}(x, y, 1)$
    \State $d \leftarrow []$
    \For{$i = 1$ to $|x|$}
        \State $d_i \leftarrow |y_i - (mx_i + b)|$
        \If{$y_i < mx_i + b$}
            \State $d_i \leftarrow -d_i$ \textit{// Negative for points below regression line}
        \EndIf
        \State Append $d_i$ to $d$
    \EndFor
    \State Filter: $d \leftarrow \{d_i : d_i < 0\}$ \textit{// Keep only negative distances}
    \If{$d \neq []$}
        \State $d^* \leftarrow \max\{|d_i| : d_i \in d\}$ \textit{// Maximum absolute negative distance}
        \State $\gamma^* \leftarrow \gamma_{\text{index}(d^*)}$
    \EndIf
\EndIf
\If{$\gamma^* = \text{null}$}
    \State \textit{// Method 3: Fallback to first valid gamma}
    \State $\gamma^* \leftarrow \min\{\gamma_i : e_i \text{ is finite}\}$
\EndIf
\State \Return $\gamma^*$
\end{algorithmic}
\end{algorithm}

\section{Supporting Mathematical and Statistical Details}
\label{app:valdx-mathematics}

\subsection{Work Done Metrics}
\label{app:valdx-work-definitions}

The Work Done metrics of \cref{sec:valdx-work} are reported in energy units but do not represent thermodynamic work or changes in protein enthalpy or entropy. Changes in either direction contribute positively. Their energy scale comes from the EX2 regime. With the predominantly closed-state approximation, the opening free energy of residue $i$ is approximately $RT\ln P_{f,i}$ (\cref{eq:bg-opening-free-energy}). The EX2 relation motivates expressing log-protection changes on an $RT$ energy scale. The Work Done metrics are nevertheless defined as statistical comparisons of protection profiles. Each profile is the ensemble-averaged BV log protection factor of \cref{eq:bg-bv-average}, calculated with that ensemble-model's own frame weights and BV coefficients.

Mean-centring separates changes in relative protection from shifts in overall protection. Each residue's absolute deviation from the mean log protection factor, scaled by $RT$, gives its centred protection score. The same deviations define a residue weight and an entropy-like contribution. Centring and weights are calculated separately for each profile over the same matched residues. Because $w_\text{opt}(X;i)=e^{-a_i}\sum_{j=1}^{N}e^{-a_j}$, the weights sum to $\left(\sum_{i=1}^{N}e^{-a_i}\right)^2$ rather than to one, and $S_\text{opt}(X;i)$ is negative wherever $w_\text{opt}(X;i)>1$.

Work opt combines the centred score and the entropy-like contribution within each residue before taking the absolute value. By the triangle inequality, $\text{Work}_\text{opt}\le\text{Work}_\text{shape}+\text{Work}_\text{density}$. The same expressions compare any two profiles $X_1$ and $X_2$ over matched residues by substituting them for $X$ and $\hat X$.

\subsection{Structural Comparison Metrics}
\label{app:valdx-structural-metrics}

\paragraph{Local mean pair-distance RMS difference.}
For each residue $i$, we construct a neighbourhood $\mathcal S_i$ from ensemble 1's mean coordinates. Within that fixed neighbourhood, we calculate the mean distance of each unique C$\alpha$ residue pair separately in each ensemble and then take the RMS difference between those means,
\begin{equation}
    \overline d_{ab}^{\,X}=\frac{1}{|X|}
    \sum_{x\in X}\lVert\mathbf r_a(x)-\mathbf r_b(x)\rVert_2,
    \label{eq:valdx-mean-pair-distance}
\end{equation}
\begin{equation}
    D_i(X_1,X_2)=
    \sqrt{\frac{1}{M_i}
    \sum_{\substack{a<b\\a,b\in\mathcal S_i}}
    \left(\overline d_{ab}^{\,X_1}-\overline d_{ab}^{\,X_2}\right)^2},
    \qquad M_i=\binom{|\mathcal S_i|}{2}.
    \label{eq:valdx-pair-rms}
\end{equation}
This unweighted quantity measures differences in local ensemble-mean pair distances, in \text{\AA}. Pair distances are invariant to rigid translation and rotation of individual structures; neighbourhood selection from mean Cartesian coordinates nevertheless depends on how those coordinates were prepared. Because the neighbourhood is selected from ensemble 1, reversing the ensemble order can change the neighbourhood and the resulting value.

\paragraph{Residue-averaged Wasserstein-1 distance.}
For residue $i$, the C$\alpha$ distances to every C$\alpha$ atom, including its zero distance to itself, are pooled over all frames of ensemble $X$,
\begin{equation}
    \Omega_i(X)=\left\{\lVert\mathbf r_i(x)-\mathbf r_j(x)\rVert_2 : j=1,\dots,N,\ x\in X\right\}.
    \label{eq:valdx-w1-pool}
\end{equation}
Frames are unweighted. As $W_1$ is computed between normalised distributions, each pool is smoothed by a Gaussian kernel density estimate (KDE), $\hat f_i^{X}$. SciPy's KDE implementation uses Scott's rule for bandwidth selection.\supercite{virtanenSciPy10Fundamental2020} Both densities are evaluated on a common grid of $K=1000$ evenly spaced points $g_1<\dots<g_K$ spanning the pooled distances of both ensembles and normalised over that grid, giving $p_{i,k}^{X}=\hat f_i^{X}(g_k)/\sum_{l=1}^{K}\hat f_i^{X}(g_l)$ and cumulative distributions $F_{i,k}^{X}=\sum_{l\le k}p_{i,l}^{X}$. The residue distance and its average over the $N$ compared residues are
\begin{equation}
    W_{1,i}(X_1,X_2)=\sum_{k=1}^{K-1}\left|F_{i,k}^{X_1}-F_{i,k}^{X_2}\right|\left(g_{k+1}-g_k\right),
    \qquad
    \langle W_1(X_1,X_2)\rangle=\frac{1}{N}\sum_{i=1}^{N}W_{1,i}(X_1,X_2),
    \label{eq:valdx-w1}
\end{equation}
in \text{\AA}. Values approaching zero indicate identical pooled distance distributions, and larger values indicate divergence between them. The pairwise heatmaps in \cref{app:valdx-pairwise} report the median over residues rather than the mean,
\begin{equation}
    \widetilde W_1(X_1,X_2)=\operatorname{median}\left\{W_{1,i}(X_1,X_2):i=1,\dots,N\right\},
    \label{eq:valdx-w1-median}
\end{equation}
also in \text{\AA}.

\paragraph{Weighted RMSF.}
To account for the non-uniform weights of structures in the ensemble, the weighted RMSF for residue $i$ is computed as
\begin{equation}
    \text{RMSF}_i(X)=\sqrt{\sum_{x\in X}p(x)\left\lVert\mathbf r_i(x)-\langle\mathbf r_i(X)\rangle\right\rVert^2},
    \qquad
    \langle\mathbf r_i(X)\rangle=\sum_{x\in X}p(x)\,\mathbf r_i(x),
    \label{eq:valdx-weighted-rmsf}
\end{equation}
where $p(x)$ is the weight of structure $x$ in ensemble $X$.

\paragraph{Dynamical local cross-correlation.}
For each ensemble $X$, we define the displacement of residue $i$ relative to its mean C$\alpha$ position and calculate its normalised displacement covariance with residue $j$,
\begin{equation}
\begin{aligned}
    \delta\mathbf r_i(t)&=\mathbf r_i(t)-\langle\mathbf r_i\rangle_t,\\
    C_{ij}(X)&=
    \frac{\langle\delta\mathbf r_i(t)\cdot\delta\mathbf r_j(t)\rangle_t}
    {\sqrt{\langle\lVert\delta\mathbf r_i(t)\rVert_2^2\rangle_t
    \langle\lVert\delta\mathbf r_j(t)\rVert_2^2\rangle_t}}.
\end{aligned}
    \label{eq:valdx-dynamical-pair-correlation}
\end{equation}
Averages are unweighted averages over ensemble frames. Trajectories were aligned on C$\alpha$ atoms before analysis. Spatial neighbours are identified using the mean inter-residue distance over frames,
\begin{equation}
    \mathcal N_i(X)=\left\{j\ne i:
    \left\langle\lVert\mathbf r_i(t)-\mathbf r_j(t)\rVert_2\right\rangle_t
    \leq8\,\text{\AA}\right\}.
    \label{eq:valdx-lcc-neighbours}
\end{equation}
The residue-level LCC is the arithmetic mean of the defined pair correlations within this neighbourhood,
\begin{equation}
    \mathrm{LCC}_i(X)=\frac{1}{|\mathcal V_i(X)|}
    \sum_{j\in\mathcal V_i(X)}C_{ij}(X),
    \qquad
    \mathcal V_i(X)=\{j\in\mathcal N_i(X):C_{ij}(X)\text{ is defined}\}.
    \label{eq:valdx-lcc}
\end{equation}
Undefined pair correlations, including those arising from zero displacement variance, are excluded. A residue with no valid pair correlations has no defined neighbourhood mean. Neighbourhood means are shown in \cref{fig:valdx-lcc-ensembles} with bands spanning one standard deviation across the contributing pair correlations. These bands describe variation among neighbours, rather than sampling uncertainty in the mean.

\subsection{Regression and Effect Sizes}
\label{app:valdx-statistics}

To assess the joint association of $\text{MSE}_\text{Training}$ and Apparent Work ($W_\text{app}$) with ground-truth Open State Recovery\%, we fitted a multiple linear regression model with standardised predictors,
\begin{equation}
    \begin{gathered}
    \text{Recovery} = \theta_0 + \theta_1 z_\text{MSE} + \theta_2 z_W + \epsilon,\\
    z_\text{MSE}=\frac{\text{MSE}_\text{Training}-\overline{\text{MSE}}_\text{Training}}{s_\text{MSE}},
    \qquad
    z_W=\frac{W_\text{app}-\overline{W}_\text{app}}{s_W},
    \end{gathered}
    \label{eq:valdx-recovery-regression}
\end{equation}
where $\theta_0$ is the fitted intercept, $\theta_1$ and $\theta_2$ are regression coefficients for the standardised predictors, and $\epsilon$ is the error term. The model was fitted separately for each candidate ensemble. Means and standard deviations were taken over that ensemble's fits, so $z_\text{MSE}$ and $z_W$ are dimensionless, while Recovery keeps its percentage units.

We calculated the additional variance explained by each predictor as the reduction in model $R^2$ when that predictor was excluded,
\begin{equation}
    \Delta R^2_i = R^2_\text{full} - R^2_{\text{without},i},
    \label{eq:valdx-delta-r2}
\end{equation}
where $R^2_\text{full}$ is the coefficient of determination for the full model and $R^2_{\text{without},i}$ is the coefficient of determination for the model excluding predictor $i$. Both models include the intercept.

We assessed differences between split type means using one-way ANOVA and quantified the fraction of total variance explained by split type using
\begin{equation}
    \eta^2 = \frac{SS_\text{between}}{SS_\text{total}},
    \label{eq:valdx-eta-squared}
\end{equation}
where $SS_\text{between} = \sum_{j=1}^{k} n_j(\bar{x}_j - \bar{x}_\text{grand})^2$ and $SS_\text{total} = \sum_{i=1}^{N}(x_i - \bar{x}_\text{grand})^2$. Here $k$ is the number of split types, $n_j$ is the number of observations in split type $j$, $N=\sum_j n_j$, $\bar{x}_j$ is the mean for split type $j$ and $\bar{x}_\text{grand}$ is the grand mean.

\subsection{Software and Hardware}
\label{app:valdx-software}

All simulations were performed using the University of Oxford's Advanced Research Cluster (ARC).\supercite{richardsUniversityOxfordAdvanced2015} Traditional MD simulations used GROMACS 2021.3.\supercite{abrahamGROMACSHighPerformance2015} Enhanced sampling protocols (T-FES) were implemented in OpenMM 8.1.2.\supercite{eastmanOpenMM7Rapid2017} AlphaFold2 structure predictions were generated using LocalColabFold (commit 1208ceb).\supercite{mirditaColabFoldMakingProtein2022,jumperHighlyAccurateProtein2021} HDXer (commit f06191e) was used for all ensemble reweighting and optimisation.\supercite{bradshawInterpretationHDXData2020}

{\emergencystretch=1em Key analysis libraries included MDAnalysis (2.6.1),\supercite{gowersMDAnalysisPythonPackage2019a} scikit-learn (1.5.2),\supercite{pedregosaScikitlearnMachineLearning2011} and SciPy (1.14.1).\supercite{virtanenSciPy10Fundamental2020} Performance benchmarks for all simulation types are given in \cref{app:valdx-performance}.\par}

The T-FES conda environment (anaconda 2022.10) included Python 3.11 with NumPy 1.26.4 for numerical operations, SciPy 1.14.1 for scientific computing, scikit-learn 1.5.2 for machine learning algorithms, MDTraj 1.10.0 for trajectory analysis, matplotlib 3.9.2 for visualisation, and ParmEd 4.2.2 for parameter file conversion between GROMACS and AMBER formats.

The LocalColabFold environment used Python 3.10, cudatoolkit 11.8 for GPU acceleration, Biopython 1.82 for handling biomolecular file formats, kalign2 2.04, hhsuite 3.3.0 and MMseqs2 17.b804f for sequence alignment, JAX 0.4.23 (jax[cuda11]) as the numerical framework, matplotlib 3.10.0 for plotting and TensorFlow 2.18.0 for numerical operations.

\subsection{Code and Data Availability}
\label{app:valdx-code-data}

To support reproducibility, we provide details and scripts for all major components of this work. This includes the ValDX workflow using a modified HDXer, associated plots and data processing scripts. The scripts for ensemble generation experiments are also provided, including topology generation, ColabFold simulations, AF2-ensemble cleaning scripts, and MD simulation files.

The structural ensembles and experimental HDX data used in this study are deposited on Zenodo (\url{https://doi.org/10.5281/zenodo.19489011}). Snapshots of the ValDX and interpretable-hdxer repositories are archived on Zenodo together with the manuscript's extended supplementary information (\url{https://doi.org/10.5281/zenodo.22758666}). Development versions of all code are maintained in the repositories listed below.

\paragraph{HDXer.}
HDXer (commit f06191e) is a Python package for MaxEnt optimisation for HDX-MS data. The package provides implementations of the Best-Vendruscolo model and frame reweighting optimisation algorithms used in this study (\url{https://github.com/Lucy-Forrest-Lab/HDXer}).

\paragraph{ValDX.}
The ValDX validation framework developed for this study was written in Python, building on a modified version of the HDXer package to directly extract parameters. The workflow scripts and analysis notebooks are split into separate repositories. The workflow repository implements peptide splitting algorithms, optimisation protocols, and metrics calculation for ensemble validation (\url{https://github.com/alexisiddiqui/ValDX}, commit a71acca). It also contains the kinetic simulator, its validation suite, and the pepsin digestion model used for the kinetic misspecification experiments (\cref{app:valdx-kinetic-simulator,app:valdx-peptide-noise}).

\paragraph{Analysis scripts.}
The interpretable-hdxer repository contains the Python scripts for generating figures, statistical analyses, and ensemble/data processing reported in this work (\url{https://github.com/alexisiddiqui/interpretable-hdxer}, commit 1d78b96).

\paragraph{Topology generation.}
The topology-generation repository contains notebooks to generate and validate topologies for each starting structure used in MD simulations. It also contains the force field description files (\url{https://github.com/alexisiddiqui/topology_generation}).

\paragraph{Traditional MD.}
Traditional MD simulations were run with a small Python package that acts as a wrapper for GROMACS, primarily to manage paths across repeated simulations (\url{https://github.com/alexisiddiqui/xMD}). Simulation parameters were obtained from \url{https://github.com/intbio/gmx_protocols} (commit d70eb3e). The equilibration protocols were modified from those provided in the \textit{gmx\_protocols} repository to separate position restraints on heavy atoms and backbone atoms across different stages of equilibration.

\paragraph{Enhanced MD.}
The original Frontier-Expansion-Sampling scripts do not correctly apply a barostat for pressure coupling (original: \url{https://github.com/Gonglab-THU-MD/Frontier-Expansion-Sampling}; T-FES: \url{https://github.com/alexisiddiqui/multi-Topology-Frontier-Expansion-Sampling}).

\paragraph{AF2.}
LocalColabFold (commit 1208ceb) was used to perform MSA subsampling (\url{https://github.com/YoshitakaMo/localcolabfold}). Simulation, initial analysis, and AF2 ensemble processing scripts for all protein systems in this study are provided in the xFold\_Sampling repository (\url{https://github.com/alexisiddiqui/xFold_Sampling}).
