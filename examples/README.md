# Thesis-map examples

The three examples illustrate a shared, versioned thesis-map workflow:

- [Crook](crook-map/map.html): *Bayesian methods for spatial proteomics*.
- [Carlos](carlos-map/map.html): *Developments in Machine Learning and Bonding Indicators for the Quantum Chemical Topology Force Field* (MPhil).
- [Vost](vost-map/map.html): *Machine Learning for Molecular Modelling and Drug Discovery*.

Each map directory contains exactly `thesis.json` and `map.html`. Open the HTML locally to explore Journey, Structure and Links, search the content, and inspect page evidence and source observations. The HTML includes the complete JSON and works offline.

All three JSON files follow schema version **2.0.0**. Rebuild scripts, curated inputs, the shared template and tests live in [tools/thesis-map](../tools/thesis-map/README.md). Source PDFs remain alongside these directories as local inputs and are ignored by Git.
