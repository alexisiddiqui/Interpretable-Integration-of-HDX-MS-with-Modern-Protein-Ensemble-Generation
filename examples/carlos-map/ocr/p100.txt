TYCHE outputs a set of distorted geometries around the input configurations,
which are checked and shuffled by GAIA. Then GAUSSIAN 09 is employed to per-
form ab initio calculations at the specified level of theory. The input files contain the
output=wfn keyword, which ensures that the molecular orbitals (or natural orbitals

for correlated wavefunctions) are printed in a .wfn file.

These orbitals constitute the input for the AIMAII code [236], which constructs
the density and performs the partition of real space in atomic basins. These are in
turn integrated to yield the atomic multipoles (in the spherical tensor formulation),
and the Ejga values. These quantities (along with some others, such as atomic

kinetic energies) are parsed and extracted by GAIA.

The multipoles as computed by AIMAII are defined in the global frame, and
must be rotated to the ALF before the kriging models can be trained. This is done
by the in-house code NORMART, which handles all the spherical harmonic algebra

and outputs plain-text files containing the features and responses for the training
