2.5.2 Maximum likelihood estimation

This subsection is concerned with how to train a kriging model. This might sound a
bit strange: in the previous subsection we have described and derived a set of equa-
tions that allow to obtain a predictive model f (x*) from a training set S = {x;, yx}.
There is, however, a problem that we have not addressed yet: given a kernel func-
tional form, such as equation 2.155, how can we estimate the hyperparameters (in this

case, @ and p) that provide a best estimation of the data?

The first idea that might come to mind is selecting a set of points that are not
contained in the training set S, and vary the hyperparameters {6;} in the way that
best recovers the true values of these points. This idea is strong because of several
reasons: it does not introduce any new assumption to the model, and in a certain
way, it allows to correct some of the inadequacies of the model. However, it has
two very strong difficulties: it requires an additional set of training points, and it is,

in general, very expensive computationally [190].

In the world of limited data and finite computational resources, a different ap-
proach is generally required. This passes by introducing a new probabilistic model
to estimate the hyperparameters. The most extended approach is called maximum
likelihood estimation; here, we estimate the probability P(y|x, {6,}), which can be
