This short digression has probably clarified how to define a probability distribu-
tion over a space of functions. It has also offered a glimpse to our objective: obtain
a stochastic process whose mean corresponds to a given objective function, and a
variance that quantifies the expected error (and thus, hopefully, provide a reason-

able error estimate to our predictions).

There is, however, one caveat. Specifying the stochastic process completely re-
quires then an infinite number of coefficients (actually, an infinite number of means,
and an infinite number of standard deviations). This is, in practice, impossible: not
only is it impossible to store all this information in a computer, but the mere recol-
lection of an infinite number of samples is a doomed procedure. We note that, in
case an infinite number of points is available, it is probably more efficient to simply

store the value of the function f at every possible point.

Let us accept the restriction to a finite number of points. In this case, we will
take the regression function to be given from a Gaussian process, which in the finite

case is simply a multivariate normal distribution:
