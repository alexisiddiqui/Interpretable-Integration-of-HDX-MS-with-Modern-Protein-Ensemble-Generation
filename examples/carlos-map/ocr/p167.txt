Figure 5.4: Symmetry projection in FFLUX. The transformation of the coordinates is

performed in the two_body_forces subroutine, before the computation of the features.

This subroutine applies the matrices Ix (which are read from a file MATRI-
CES.txt in the execution directory) to the Cartesian vectors in the form 5.16. After-
wards, the set of symmetry-equivalent Cartesian vectors are passed to the fflux_compute_distances,
which implements Kabsch algorithm to find an optimal rotation that superimposes
all Cartesian coordinates, and computes the RMSD between them, which serves as

distance.

At the end of this subroutine, the Cartesian coordinates (stored in the global
variables xxx, yyy and zzz, as defined in the config module), are in the appropriate
symmetry region, and are returned to the main program. These are employed by
the subroutines fflux_calc_features and fflux_calc_forces, which are unchanged with

respect to the original implementation, to compute the forces.

This implementation is quite elegant in the sense that is does not need to change
anything in the previous code: the featurization system, the forces subroutines and
the training pipeline can be kept untouched. Only the input/output subroutines

had to be altered, to read the representation matrices.
