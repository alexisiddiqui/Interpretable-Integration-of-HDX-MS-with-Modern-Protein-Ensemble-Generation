yw =Cu (C.41)

6’ = cect (C.42)

Here, C is a rotation matrix, an orthogonal matrix with determinant +1 that ro-
tates the local frame axes into the laboratory frame axes, and the prime indicates the
laboratory frame multipoles. Note that the charge is independent of the system of
coordinates, since it is a scalar magnitude. Since C T — C-1 it is not uncommon to
see transposed and untransposed matrices interchanged, for a rotation matrix that

rotates the laboratory frame axes into the local frame axes.

The definition of the rotation matrix C employed in FFLUX is given towards the
end of Section 3.1.2.
