Observed TCR contacts in the local PDB crystal comparison. Green indicates the fraction of structures in which a pMHC residue has a heavy atom within 4.5 Å of TCR chains D or E. G12D combines 7OW6 and 7PB2; WT uses 7OW5. Each denominator includes only structures in which the residue is modelled. Internal HLA–β2m–peptide contacts are excluded. The peptide sticks and HLA surface use the same scale, with peptide residue values shown below. Grey denotes missing structural evidence, including the peptide-free panel, for which this set contains no observed complex. Contacts measured in each crystal are mapped by verified author residue identities onto the matched display structures used for the GQT and PeSTo figures. These fractions describe this small, related TCR set rather than population-level binding probabilities.
